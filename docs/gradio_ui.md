# Інтерфейс Hunyuan3D

Встановлення й запуск: [README](../README.md).

1. Завантажте фото одного предмета.
2. За потреби увімкніть колір з обох боків.
3. Натисніть «Побудувати 3D-модель» та дочекайтеся генерації.
4. Обертайте модель у переглядачі або завантажте GLB.

Потрібна NVIDIA GPU з CUDA. Перший запуск завантажує ваги.
Помилки моделі записуються в термінал сервера.
