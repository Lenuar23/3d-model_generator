# Генерація ракурсів Zero123++ v1.2

Відкрийте [ноутбук](../notebooks/zero123plus.ipynb) через **File → Upload notebook**
у Google Colab. У **Runtime → Change runtime type** виберіть **T4 GPU**
в **Hardware accelerator** та **2026.07** у **Runtime Version**. Ця версія
містить потрібний Python 3.12.13. Під'єднайтеся до вибраного середовища.
Перший запуск потребує приблизно 15 ГБ місця для CUDA-пакетів і ваг.
[Версії середовищ Colab](https://research.google.com/colaboratory/runtime-version-faq.html).

У першій комірці `MODE = "upload"` відкриває діалог вибору одного фото.
`MODE = "batch"` бере всі десять фото з набору Студента 2. Маніфест і
завантажувач беруться з [закріпленого коміту завдання 3](https://github.com/Lenuar23/3d-model_generator/tree/e2f81456de75b15aec6d4839bb1ecb9c44c73177).
Байти кожного фото перевіряються за SHA-256. Запустіть комірки зверху вниз
і збережіть ZIP наприкінці. Усередині будуть підготовлені PNG, сітки та `run.json`.

Середовище моделі ізольоване від ядра Colab та залежностей основного проєкту.
Файл [залежностей](../notebooks/zero123_requirements.in) фіксує ключові
версії, зокрема PyTorch 2.5.1 із CUDA 12.1, Diffusers 0.27.2 і NumPy 1.26.4.
Ноутбук містить той самий код запуску, що й [локальний скрипт](../scripts/run_zero123.py).
Його можна відкрити в Colab до злиття цієї гілки.

## Обробка фото й формат виходу

Фото повертається за EXIF, обмежується 1024 пікселями по довшій стороні
та приводиться до RGBA. Наявна прозорість використовується як маска.
Для непрозорих фото `rembg` застосовує `u2netp` на CPU. Якщо маска порожня,
зберігається початковий кадр і причина в `run.json`. Предмет масштабується
зі збереженням пропорцій і центрується на сірому квадраті 320 × 320.

За замовчуванням використано seed 42, 28 кроків та guidance scale 4.
28 кроків відповідає типовому режиму для предметів у документації Zero123++.
Вихід 640 × 960 — сітка з двох стовпців і трьох рядків. Кожен ракурс
має 320 × 320 пікселів.
Версія v1.2 використовує висоти 20° і −10° та поле огляду 30°.
У v1.1 висоти інші. Геометрія й узгодженість поверхонь між ракурсами
потребують окремої оцінки. [Офіційна документація Zero123++](https://github.com/SUDO-AI-3D/zero123plus#camera-parameters).

`run.json` містить SHA-256 входів і сіток, ревізії, режим підготовки,
версії пакетів, GPU, тривалість і пікову виділену VRAM. Успіх пакетного
режиму означає десять збережених сіток потрібного розміру. Помилки
записуються окремо для кожного фото або для всього запуску.

## Локальний запуск на Windows

Створіть окреме середовище за наявності NVIDIA GPU та драйвера з підтримкою
CUDA 12.1. Прямий режим FP16 у прикладі авторів потребує близько 5 ГБ VRAM.
Опція `--vae-tiling` зменшує пік пам'яті під час декодування. Цей режим
може змінювати тон між ділянками зображення.
[Вимоги Zero123++](https://github.com/SUDO-AI-3D/zero123plus#get-started),
[Diffusers VAE tiling](https://huggingface.co/docs/diffusers/v0.30.3/en/optimization/memory#tiled-vae).

```powershell
uv venv --python 3.12 data/zero123_runtime
uv pip install --python data/zero123_runtime/Scripts/python.exe -r notebooks/zero123_requirements.in
$env:HF_HOME = (Join-Path (Get-Location) 'data/zero123_cache')
$env:HF_HUB_DOWNLOAD_TIMEOUT = '120'
data/zero123_runtime/Scripts/python.exe -u scripts/run_zero123.py --photo data/test_photos/01_simple_apple.jpg --output-dir data/zero123_single --vae-tiling
```

Підготуйте `data/test_photos/` за [інструкцією набору](https://github.com/Lenuar23/3d-model_generator/blob/e2f81456de75b15aec6d4839bb1ecb9c44c73177/docs/test_photos.md).
Потім виконайте пакетний запуск. Вказана папка результатів має бути новою.

```powershell
data/zero123_runtime/Scripts/python.exe -u scripts/run_zero123.py --batch --photos-dir data/test_photos --output-dir data/zero123_batch --seed 42 --steps 28 --vae-tiling
```

Ваги v1.2 у форматі safetensors займають приблизно 5,58 ГБ на диску.
Код пайплайна Apache 2.0, ваги CC BY-NC 4.0. Під час використання ваг
застосовуються умови некомерційної ліцензії.
[Ревізія ваг](https://huggingface.co/sudo-ai/zero123plus-v1.2/tree/2da07e89919e1a130c9b5add1584c70c7aa065fd),
[ревізія коду](https://huggingface.co/sudo-ai/zero123plus-pipeline/tree/983e66d28a3637ddd8e3e2fd8165cdff32230872),
[умови авторів](https://github.com/SUDO-AI-3D/zero123plus#license).

## Перевірка на десяти фото

5 листопада 2026 року локальний запуск на NVIDIA GeForce RTX 4050 Laptop
GPU створив **10 із 10** PNG-сіток. Використано FP16, seed 42, 28 кроків,
guidance scale 4 і `--vae-tiling`. Усі десять входів пройшли підготовку
через `u2netp`. Для кожної сітки перевірено PNG, RGB, розмір 640 × 960,
SHA-256 і наявність варіації кольору в кожному з шести ракурсів.

Один виклик займав 13,54–14,71 с після завантаження моделі. Десять
викликів разом зайняли 138,72 с. Пікова пам'ять, виділена PyTorch,
становила 3,91 ГіБ. Ці виміри не включають підготовку фото й завантаження
ваг. Локальні файли лежать у `data/zero123_batch/`. Перелік входів,
контрольні суми, час і конфігурацію збережено у
[звіті запуску](zero123plus_validation.json). Код підготовки й генерації
з локального запуску вбудовано в ноутбук. Окремий запуск у Colab ще не перевірено.

| Вхід | Візуальне спостереження |
| --- | --- |
| Яблуко | Деякі ракурси спотворюють контур і домальовують текстуру. |
| Тенісний м'яч | Є домальовані круглі плями та зміни швів. |
| Алеппське мило | Частина ракурсів змінює форму й рельєф штампа. |
| Соснова шишка | Предмет впізнаваний. Деталі лусочок різняться. |
| Гумова качка | Предмет впізнаваний. Форма дещо змінюється, під ним лишається фрагмент тла. |
| Навісний замок | Замок впізнаваний. Дужка деформується. |
| Сталева ложка | Пропорції ручки й чаші різняться між ракурсами. |
| Срібний чайник | Геометрія й орнамент відрізняються між ракурсами. |
| Прозора пляшка | Залишається зелений колір трави. У першому ракурсі верх обрізано. |
| Скляний келих | Матеріал виглядає непрозорим, схожим на метал. |

Спостереження описують якість ракурсів. Точність 3D-реконструкції ще
потрібно оцінити на наступних етапах.

Додатково порівняли яблуко з тим самим seed на тому самому GPU.

| Кроки | VAE tiling | Час | Пік PyTorch |
| --- | --- | --- | --- |
| 28 | Увімкнено | 14,71 с | 3,91 ГіБ |
| 75 | Увімкнено | 35,22 с | 3,91 ГіБ |
| 28 | Вимкнено | 19,57 с | 5,00 ГіБ |

На 75 кроках перший ракурс виглядає дещо природніше, але праворуч унизу
залишилися деформації та домальована текстура.
Без tiling переходи тону плавніші, а домальована текстура на першому й
останньому ракурсах залишається.
